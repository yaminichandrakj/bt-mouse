# BT Mouse v1.3.10

## Camera, snapshots, and recordings

- Added a phone-side snapshot gallery in Camera & Mic. Full-quality snapshots are kept on the phone and can be opened from the gallery.
- Moved two-way live audio into the Camera & Mic section so camera, microphone, and live audio controls are together.
- Leaving the Camera & Mic section no longer sends a camera-stop command. Taking a snapshot during a live feed reuses the active camera frame instead of opening the webcam a second time.
- The live webcam indicator now reports whether a recording is actually active. Recording start failures, including a missing MP4 encoder, are reported in the app.
- New webcam recordings use MP4 for phone playback. Older MJPEG AVI webcam files are converted to MP4 when opened or downloaded from the phone.

## Live audio

- Fixed phone microphone playback to the PC: incoming PCM audio is now converted to the selected PC output device's sample rate and channel layout before playback.
- The phone reports when microphone audio reaches the PC, distinguishes a waiting session from received audio, and displays whether the PC is recording the session.
- PC audio output devices are released when the session stops.

## Tasks and system performance

- The task and hardware screen now scrolls through the full process list instead of showing only its first 30 entries.
- The PC returns up to 200 processes, including smaller processes, ordered by CPU and memory use.
- Ending a process reports the PC's result to the phone and refreshes the list after success.
- System CPU usage uses a measured sample instead of an uninitialized first reading.

## Compatibility and validation

- Android app version: 1.3.10 (version code 17).
- Windows companion and server protocol version: 1.3.10.
- GitHub Actions builds and existing companion checks are run for this release. Live camera, audio-device, and Android playback behavior still needs verification on the target PC and phone.
