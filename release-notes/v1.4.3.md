# BT Mouse v1.4.3

## Off-Network Access Fix: Companion Can Publish Its Address

- **Publishing no longer blocked by Cloudflare (`pc_server/remote_tunnel.py`)**:
  - The companion's address publish was rejected with HTTP 403 before reaching the Worker:
    Cloudflare answers Python's default `Python-urllib` User-Agent with error 1010. The
    companion now identifies itself as `BTMouse-Companion`, so the signed record is stored
    and the phone can resolve the tunnel address from mobile data.
  - A rejected publish now shows what the Worker or Cloudflare actually returned, instead of
    a generic "check the Worker URL".

- **Clearer phone feedback (`ConnectionScreen.kt`)**:
  - When the internet lookup fails, the phone now says why (for example "PC is offline") before
    falling back to the local Wi-Fi address, instead of failing silently on `ws://` addresses
    that only work on the PC's own network.

- **Tests (`pc_server/test_server.py`)**:
  - New regression check that the publish request is a `PUT` with the named User-Agent.

## Compatibility and Versioning

- Android app version: 1.4.3 (version code 27).
- Windows companion and server protocol version: 1.4.3.
- Update both the phone app and the companion. No re-pairing needed: the QR, Worker URL and
  PC identity from v1.4.2 keep working.
