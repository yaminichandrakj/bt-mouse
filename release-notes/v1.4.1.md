# BT Mouse v1.4.1

## Native Icons, One Companion at a Time, Truthful Connection Status & Undistorted Camera Video

- **Professional Icon Set Instead of Emoji (`pc_server/app_gui.py`, `IconLabel.kt`, `UtilitiesScreen.kt`, `KeyboardScreen.kt`, `WritingPadScreen.kt`)**:
  - The Windows companion draws every button, sidebar and media-library icon from the built-in Windows icon font (Segoe Fluent Icons, with Segoe MDL2 Assets on Windows 10), with the active page highlighted in the sidebar and the app logo in the header.
  - The Android app uses Material icons in filter chips, buttons, folder badges and recording rows through new shared `IconLabel` / `ChipIcon` components.
  - Emoji removed from both apps; labels and titles rewritten in shorter sentence case.
  - Calmer companion palette: only primary actions are filled and only destructive actions (Delete, Stop server) are red.

- **Only One Companion and One Server (`pc_server/app_gui.py`, `pc_server/server.py`)**:
  - Opening the companion again (shortcut, sign-in startup or manual start) now brings the running window to the front instead of starting a second window and a second server.
  - UDP ports `53530` / `53535` are bound exclusively on Windows (`SO_EXCLUSIVEADDRUSE`), so a stray second server can no longer silently share them.

- **Connection Status That Matches Reality (`server.py`, `app_gui.py`, `WifiClientManager.kt`, `RemoteWanManager.kt`, `MainScreen.kt`, `ConnectionScreen.kt`)**:
  - The companion shows **Connected: phone · Wi-Fi, Bluetooth** whenever the phone was heard on any link in the last 8 seconds. Previously one of several concurrent links closing or failing over flipped it to "Disconnected" while the phone was still connected.
  - The Android app shows an amber **No response** state when the PC stops answering instead of a green "Connected". Wi-Fi gives up after 9 seconds without a reply (was 30 seconds) and a half-open Remote WAN socket is closed after 20 seconds.

- **Undistorted Phone Camera Video (`PhoneCameraStreamer.kt`, `server.py`)**:
  - The phone picks a camera size with the right aspect ratio and centre-crops to 16:9 or 9:16 before scaling, instead of force-scaling frames to the selected resolution (which stretched 4:3 sensor modes and rotated frames).
  - Output orientation follows the rotated frame, so **Rotate 90°** produces an upright portrait stream instead of a squashed landscape one.
  - The companion letterboxes frames for the virtual camera (OBS, Zoom, Teams) and MP4 recordings instead of stretching them to a fixed size.

- **Android Layout and Remote Access (`*Screen.kt`, `RemoteWanManager.kt`, `README.md`)**:
  - 69 button and chip labels are single-line with an ellipsis instead of wrapping word by word.
  - Remote WAN accepts `ws://` addresses on Tailscale (`100.64.0.0/10`, `*.ts.net`), which is already end-to-end encrypted.
  - README documents remote access through Tailscale or a Cloudflare Tunnel (`wss://`).

## Compatibility and Versioning

- Android app version: 1.4.1 (version code 25).
- Windows companion and server protocol version: 1.4.1.
- CI now launches the companion twice to verify the single-instance guard, and renders every companion page at 100% and 150% scaling.
