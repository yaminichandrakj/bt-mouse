# Lanyard v1.9.3 — Update prompts and unlock feedback

## Updates

- Lanyard for PC checks for stable releases on startup and once a day while running. It asks before downloading and installing; choosing **Later** stops repeat prompts for that version.
- The Android app checks on startup and once a day while open. It asks before downloading an APK, then opens Android's installer for confirmation. Choosing **Later** dismisses that release until a newer one is available.
- Fixed the Windows companion updater so the replacement EXE starts with a fresh PyInstaller environment.
- Existing v1.9.2 installations need v1.9.3 installed once through the current manual update flow. Automatic update prompts begin with this release and apply to later releases.

## Phone unlock

- If the PC does not reply to a phone unlock request, the phone now shows a clear message after 30 seconds instead of silently ending the wait.

## Compatibility and versioning

- Android, Lanyard for PC and the protocol are all version 1.9.3 (Android `versionCode` 37).
