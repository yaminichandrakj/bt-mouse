# Lanyard v1.9.6 — Refined Cross-Device Experience (Lenovo Smart Connect)

## Cross-Device Gallery & Smart Media Hub

- The PC companion's Library page is now an interactive Cross-Device Media Hub with responsive Grid and List views.
- High-quality thumbnails for photos and videos are generated and cached on the fly.
- Integrated full-screen Lightbox viewer (`MediaViewerModal`) with arrow-key navigation, file metadata, and one-click actions: Download to PC, Open with Default App, Show in Explorer, and Copy to Clipboard.
- The PC Companion now discovers and requests camera roll photos and videos shared by connected phones and tablets.
- Added device and category filtering (All, Photos, Videos, Audios) with real-time search.

## Share Hub (Cross-Device File Transfer)

- Introduced an interactive Drag & Drop Zone on the Devices page for instantaneous file transfers from Windows Explorer.
- Added one-click recipient device selector chips to easily direct files and clipboard contents to any connected phone or tablet.
- One-tap "Send Clipboard Now" transfers copied text or screenshots directly as files.
- Upgraded the transfers feed with rich cards showing direction badges, live throughput metrics (MB/s), smooth progress bars, and direct Open / Show in folder actions.

## Cross Control & Spatial Workspace

- Overhauled the display layout canvas with realistic monitor stands, inner display surfaces, and smartphone/tablet bezels with camera notches.
- Added magnetic snap guidelines when dragging devices along monitor edges and visual boundary chevrons indicating cursor transition points.
- Prominent Cross Control status banner with active target switcher pills and keyboard shortcut reminders.
- Upgraded live stream window with floating translucent navigation controls (Back, Home, Recents, Notifications, Lock, and Audio Mute).
- Refined mobile RemotePad screen with tactile gesture guides, rounded glass navigation dock, and streamlined text input.

## Compatibility and versioning

- Android, Lanyard for PC and the protocol are all version 1.9.6 (Android `versionCode` 40).
