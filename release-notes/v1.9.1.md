# Lanyard v1.9.1 — New signing key, working updates, edge crossing

## Reinstall the phone app once

- The Android app is now signed with a new private key. The old key was published in
  this repository by mistake, so anyone could have signed an app that installs over Lanyard.
- Android won't accept an update signed with a different key. **Uninstall Lanyard on each
  phone and tablet, then install `Lanyard-v1.9.1.apk`.** Pair with the PC again afterwards.
- After this, updates install normally again.

## Lanyard for PC updates itself again

- **Check for updates** now really installs the new version. Until now the install step
  quit before doing anything, so you had to download each release yourself.
- v1.9.0 and older still have the broken updater: download `Lanyard-Companion.exe` from this
  release once by hand. Updates from then on happen inside the app.
- The Windows download is now called `Lanyard-Companion.exe`. Updating an old
  `BT-Mouse-Companion.exe` replaces it with `Lanyard-Companion.exe` in the same folder, and
  starting with Windows follows the new file.

## Moving the mouse onto your phone

- Pushing the mouse off a screen edge toward a placed phone or tablet now crosses over,
  even when your hand drifts up or down a little while pushing. Before, that drift was
  read as sliding along the edge, so the crossing hardly ever happened.

## Quick apps

- One list: apps saved on the PC and this phone's own shortcuts sit together under
  **Your quick apps**, and each one has an ✕ to remove it.
- **Browse PC apps** has one **Add** button per app. Apps you add show on every phone
  paired with the PC.
- The app list no longer empties and refills while you browse or search it. The phone waits
  until the full list has arrived from the PC, then swaps it in once.

## Compatibility and Versioning

- The project is now at github.com/yaminichandrakj/lanyard. The old address redirects, so
  older apps still find updates.
- Android, Lanyard for PC and the protocol are all version 1.9.1 (Android `versionCode` 35).
