# BT Mouse v1.3.12

## Android Background Sessions & Foreground Service

- Added `CompanionSessionService`, an Android 14+ compliant Foreground Service with notification support:
  - Keeps explicitly user-started live camera feeds, PC audio playback, and phone microphone sessions connected when switching apps or locking the screen.
  - Dynamically manages foreground service types (`connectedDevice`, `microphone`, `mediaPlayback`) according to active streams.
  - Features an ongoing notification with clear status ("Live Audio active", "Camera feed active") and quick actions:
    - **Stop Stream**: Stops all active media capture without terminating the companion link.
    - **Disconnect**: Safely disconnects the transport and shuts down the background service.
  - Acquires a power wake-lock capped to 1 hour to prevent runaway battery drain while streaming in the background.

## Connection Supervisor & Exponential Backoff Reconnection

- Implemented an intelligent connection supervisor for user-approved endpoints:
  - Automatically detects unexpected transport drops across Wi-Fi, Bluetooth RFCOMM/HID, and WAN.
  - Reconnects using exponential backoff (2s, 4s, 8s, 16s, 30s) up to 5 attempts before cleanly timing out.
  - Cleans up stale sockets and connection jobs between attempts to prevent duplicate traffic or battery drain.
  - Real-time reconnection banner with live countdown, retry trigger, and immediate cancel controls.
  - Distinguishes intentional user disconnects (Disconnect button, mode switches) from network drops to avoid unwanted reconnection loops.
  - Never auto-starts camera capture or audio recording without explicit user action.

## Settings & User Control

- Added dedicated **Connection & Background Sessions** settings card:
  - **Background Companion Session**: Toggle foreground service persistence for live media when switching apps.
  - **Automatic Reconnect**: Toggle automatic reconnect with exponential backoff on network drop.
- Added runtime `POST_NOTIFICATIONS` permission request for Android 13+ (API 33+).

## Windows Sign-In Startup Self-Healing

- Added `_heal_startup_path_if_registered()` to the PC companion:
  - If Windows sign-in startup is enabled in `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, verifies that the registered path points to the current running binary and contains `--minimized`.
  - Automatically updates the registry if the companion executable was moved, renamed, or updated.
