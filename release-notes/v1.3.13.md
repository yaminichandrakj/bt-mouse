# BT Mouse v1.3.13

## Concurrent Transports & Measured Failover

- **Real-Time Latency & Transport Health Measurement**:
  - Implemented continuous round-trip ping measurement (`client_time` on ping echoed in pong) across local Wi-Fi, Bluetooth RFCOMM, and authenticated Remote WAN.
  - Computes round-trip time (RTT) and determines health status based on transport latency thresholds and missed heartbeat windows.
  - Automatic Failover Supervisor dynamically routes input commands over the healthiest, lowest-latency path (Wi-Fi ➔ Bluetooth RFCOMM ➔ Bluetooth HID ➔ Remote WAN).

- **Input Sequencing & Deduplication**:
  - Input packets (mouse movement, clicks, scrolling, keystrokes, and media commands) are stamped with an atomic client session UUID and incrementing sequence number (`seq`).
  - Server-side sliding sequence deduplication window (`_cmd_seq_lock` & `_last_cmd_seq`) discards out-of-order or duplicate packets across concurrent transports, eliminating double clicks or jumpy cursor movement during network handoffs.

- **Seamless Path Switching & Held Button Prevention**:
  - Handshake protocol emits `path_switch` upon transport migration, prompting the server to release all virtual mouse buttons and modifier keys via `_release_mouse_buttons()`.
  - Old transport releases local virtual buttons (`sendMouseButton(0)`) to ensure zero stuck or dragged mouse states.
  - Automatically queries media status (`queryMedia()`) over the newly selected transport to ensure real-time track metadata consistency.

- **UI Status & Settings Controls**:
  - **Live Transport Pill**: Main top bar and Connection screen display live active transport and ping latency (e.g., `Wi-Fi • 12ms`, `Bluetooth RFCOMM • 26ms`, `Remote WAN • 78ms`).
  - **Automatic Measured Failover Toggle**: Added a user setting in **Connection & Background Sessions** to enable or disable automatic path failover.

- **Companion Server Hardening**:
  - Hardened `_release_mouse_buttons()` to defensively handle missing keyboard/mouse attributes and avoid test/mocking exceptions.
  - Expanded regression test suite to 28 passing unit tests, covering transport handoffs, ping time echoing, and sequence deduplication.
