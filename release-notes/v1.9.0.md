# Lanyard v1.9.0 — Encrypted, smoother and easier to set up

## Everything between your devices is encrypted

- Phone ↔ PC links (Wi-Fi, Bluetooth and internet) now start with a fresh key exchange
  (X25519, checked against your pairing PIN). Everything after that is sealed with
  ChaCha20-Poly1305. Someone listening on a shared network sees only scrambled data, and a
  changed message is rejected.
- Phone ↔ tablet direct links are sealed too, with a key from the family handshake that
  never goes over the network.
- If the PC restarts, phones agree a new key by themselves.
- An older app on either side keeps working, unencrypted, until both are on 1.9.0.

## Smooth mirroring (beta)

- **Devices › Live › Smooth mirroring (beta)** turns on real video instead of a run of
  pictures when you mirror another phone or tablet: up to 24 frames a second at about
  2 Mb/s. The shared device's hardware encoder makes it; yours decodes it.
- If the picture stays black, turn the switch off. Devices that can't decode it go back to
  pictures automatically.
- The PC's Mirror window still uses pictures.

## First-run setup guide

- New devices open a single page with every switch Android makes you turn on yourself:
  pairing with the PC, notifications, background running, Lanyard control, the Lanyard
  keyboard and the microphone. Each has its own button and turns green when done.
  Reopen it any time from **Devices › Setup guide**.

## Fixes and polish

- **Typing from the laptop follows its keyboard layout**: German, French, Indian and other
  layouts type the right characters, including AltGr keys like @ and €.
- **Sending big files from the phone** no longer makes a full temporary copy first. Most
  file apps let Lanyard read the original directly.
- Restarting the server in Lanyard for PC now ends the old background work cleanly.
- Mirrored pictures are slightly smaller so encrypted ones still fit one network packet.

## Compatibility and Versioning

- Android app version: 1.9.0 (version code 34). Encryption needs Android 9 or later, which
  the app already requires.
- Windows companion and server protocol version: 1.9.0.
- Pairing, settings and recordings carry over. The app updates in place.
