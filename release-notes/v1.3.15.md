# BT Mouse v1.3.15

## Desktop UI Sharpness, High-DPI Scaling & Architecture Determinations

- **Native Windows High-DPI Display Scaling (Phase 7)**:
  - **Per-Monitor V2 DPI Awareness:** Enabled `DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2` (`SetProcessDpiAwarenessContext(-4)`) with multi-tier fallback to Per-Monitor Aware and System DPI Aware. Eliminates blurry font rasterization and fuzzy bitmap scaling across Windows 10 and 11.
  - **Tkinter Font Density Calibration:** Dynamically queries hardware display density using `GetDpiForSystem()` / `GetDeviceCaps` and calibrates the Tkinter font rasterizer (`tk scaling dpi / 72.0`). All typography, buttons, and status badges render razor-sharp at 100%, 125%, 150%, 175%, and 200% scaling.
  - **Proportional Window Geometry & Centering:** Automatically scales base window bounds (`800x780`) and minimum dimensions (`720x680`) by the monitor scale factor, centering the companion window upon launch.
  - **Native Companion Specification:** Published an exhaustive technical component inventory across transports, input injection, media, virtual camera, diagnostics, and self-healing updaters in `docs/native_companion_inventory_and_ui_sharpness.md`.

- **Laptop Unlock Feasibility & Security Determination (Phase 6)**:
  - Conducted an in-depth security and platform evaluation of the Windows Secure Desktop (`Winlogon`), User Interface Privilege Isolation (UIPI), the deprecated Windows Companion Device Framework (CDF), and FIDO2 enterprise limitations.
  - Formally closed remote workstation unlock as unsupported on target platforms in `docs/laptop_unlock_feasibility.md` in strict adherence to security constraints against storing passwords or injecting simulated credentials on the secure desktop.
  - Remote Workstation **Locking** (`Win+L`) remains active, safe, and fully operational.

- **Automated Regression Test Suite**:
  - Added `DpiScalingTests` in `pc_server/test_server.py` verifying display scale retrieval and non-raising awareness initialization.
  - All 32 companion regression checks passing.
