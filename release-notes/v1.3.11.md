# BT Mouse v1.3.11

## Recordings Manager, Explorer Integration, and Deletion

- Added a full-featured **Recordings** manager tab to the PC companion with table navigation, live search, category filtering (Audio, Video, Snapshots), sorting (Newest, Oldest, Name, Size), disk space gauge, and Explorer actions:
  - **Show in Explorer**: Selects and highlights the chosen recording file directly in Windows File Explorer.
  - **Open in File Explorer**: Opens the recordings directory folder in Windows File Explorer.
  - **Copy File Path**: Copies the absolute path of the selected recording to the system clipboard.
  - **Delete Recording**: Deletes recordings from the PC with a confirmation dialog, safe path verification, active-recording checks, and automatic catalog refresh.
- Added deletion controls on Android:
  - Recorded PC files and downloaded phone copies can now be deleted from the recordings library with confirmation dialogs.
  - Catalog updates sync immediately across Wi-Fi, Bluetooth, and WAN.

## PC Camera Snapshots Directory & Gallery

- Snapshots taken on the PC are now saved directly to `%LOCALAPPDATA%\BTMouse\Snapshots` as date-stamped files (`snapshot_YYYYMMDD_HHMMSS.jpg`).
- Added "Open Snapshots Folder" buttons in both the Desktop Controls and Recordings tabs on the PC companion.
- Android snapshot gallery now stores full-quality snapshots in user-accessible storage (`Android/data/com.btmouse.app/files/Pictures/Snapshots`), migrates existing internal files automatically, displays the directory location, and provides Open (via system viewer) and Delete actions.

## PC Master Volume & Media State

- Fixed the PC master volume issue: resolved COM apartment threading mode conflicts (`RPC_E_CHANGED_MODE` 0x80010106) between pycaw and WinRT/asyncio using a safe apartment context manager.
- Added explicit user-friendly error reporting when Windows has no active default audio playback device.
- Ensured volume level, mute status, and volume availability flags update atomically on every volume change.
- Fixed SMTC session priority: commands (play/pause toggle, next, previous) now prioritize actively Playing sessions over stale background Paused sessions.
- Added decoded album artwork display on Android with bandwidth-efficient on-demand retrieval, keeping album artwork distinct from the selected-region video preview.

## Quick Apps Discovery & Sync

- Hardened `update_quick_apps` to prevent shortcut loss: if the query cache is empty or expired, the companion falls back to disk enumeration and saved quick apps before updating.
- Preserved custom shortcut names edited in the PC companion during Start Menu discovery.
- Added `launch_app_response` handling across Wi-Fi, Bluetooth, and WAN on Android to notify the user upon successful launch or explain when a shortcut was moved or removed.
- Optimized Quick Apps polling in Android: removed constant 5-second polling loops in favor of connection and user-triggered refresh.

## Compatibility and Versioning

- Android app version: 1.3.11 (version code 18).
- Windows companion and server protocol version: 1.3.11.
- All 23 companion regression checks passing.
