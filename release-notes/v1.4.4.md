# BT Mouse v1.4.4

## Reliable Internet Access on Flaky Networks

- **Address publishing retries within seconds (`pc_server/remote_tunnel.py`)**:
  - On a flaky network (for example a campus Wi-Fi that occasionally drops a secure connection),
    a single timed-out publish to the Worker showed "handshake operation timed out" and left the
    phone without the PC's address until the next refresh four minutes later.
  - The companion now retries after 5 seconds, backing off to 60, and gives each attempt 20
    seconds instead of 10.
  - When the address is published the status says **Internet access on — your phone can reach
    this PC from anywhere**, so a working publish is easy to tell from a stuck one.

## Compatibility and Versioning

- Android app version: 1.4.4 (version code 28).
- Windows companion and server protocol version: 1.4.4.
- Only the companion changed. Updating from v1.4.3 works in-app (**Check for updates**); no new
  scan or settings change is needed.
