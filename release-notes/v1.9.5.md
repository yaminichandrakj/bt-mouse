# Lanyard v1.9.5 — Phone unlock reliability

## Phone unlock

- The PC now lets Windows' credential provider decide whether to accept an unlock request instead of rejecting it based on a lock-screen state check that can be wrong.
- After Windows accepts an unlock request, the phone refreshes PC lock status immediately so its Lock/Unlock button follows the result sooner.

## Compatibility and versioning

- Android, Lanyard for PC and the protocol are all version 1.9.5 (Android `versionCode` 39).
