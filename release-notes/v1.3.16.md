# BT Mouse v1.3.16

## Connectivity Restoration, Windows 11 Fluent & Android UI Upgrade, and Security Hardening

- **Windows 11 Fluent Desktop Companion UI (`pc_server/app_gui.py`)**:
  - **Native DWM Dark Titlebar & Rounded Window Corners:** Integrated `dwmapi.DwmSetWindowAttribute` for `DWMWA_USE_IMMERSIVE_DARK_MODE`, `DWMWA_WINDOW_CORNER_PREFERENCE` (`DWMWCP_ROUND`), and custom caption colors matching the `#111622` header surface.
  - **Fluent Left Navigation Rail:** Replaced the cramped 7-tab top `ttk.Notebook` bar with a modern Windows 11 left sidebar featuring active cyan accent indicators, smooth hover transitions, and a persistent Quick Pairing Info card (`IP`, `UDP Port`, and `6-Digit PIN`).
  - **Refined Dark Cards & Controls:** Styled dark comboboxes, spinboxes, alternating-row Recordings Treeview, and hover-responsive action buttons across all 8 views—requiring zero additional third-party dependencies so `BT-Mouse-Companion.exe` stays fast and lightweight.

- **Cohesive Android Material 3 / Fluent Dark UI Upgrade (`MainScreen.kt`, `TouchpadSurface.kt`, `VirtualScrollWheel.kt`, `Color.kt`)**:
  - **Unified Obsidian-Slate Palette:** Synchronized surface, card, border, and accent colors (`#0B0F17`, `#111622`, `#151C28`, `#38BDF8`, `#6366F1`) between the Android app and Windows companion.
  - **Interactive Header Transport Pill & Smooth Crossfades:** Added a live transport and latency pill in the top bar that jumps to the Connect screen on tap, smooth 180ms `Crossfade` transitions between tabs, and re-enabled the **Pen / Graphics Slate** tab (`WritingPadScreen`).
  - **Precision Glass-Grid Trackpad & Tactile Scroll Wheel:** Added a subtle dot-matrix precision grid, dynamic drag-lock border glow, multi-ring touch halos, and interactive scroll-wheel tick marks.

- **Android Coordinator & Permission Gate Fix (`MainActivity.kt`, `BtMouseApplication.kt`)**:
  - Moved `ConnectionCoordinator`, `SettingsRepository`, and `AirMouseManager` to application scope (`BtMouseApplication`) and invoked `connectionCoordinator.initialize()` unconditionally at startup.
  - Resolved a critical regression where denying optional `POST_NOTIFICATIONS` or `BLUETOOTH_ADVERTISE` permissions prevented `connectionCoordinator.initialize()` from ever running, leaving Bluetooth, Wi-Fi, and Remote WAN inoperable.
  - Preserved active sockets and `CompanionSessionService` across screen rotations and activity backgrounding when background sessions are enabled.

- **Instant QR Code Pairing & Multi-Homed Wi-Fi Handshake (`pc_server/app_gui.py`, `ConnectionScreen.kt`, `WifiClientManager.kt`)**:
  - Embedded the 6-digit pairing PIN (`pin` and `token`) directly inside the local Wi-Fi and Remote WAN QR code payloads in `pc_server/app_gui.py` and wired `ConnectionScreen.kt` to auto-populate and save the scanned PIN before initiating the handshake.
  - Relaxed `connect_ack` verification in `WifiClientManager.kt` to match source port or host address so multi-homed Windows PCs (Wi-Fi + Ethernet, VPN, WSL adapters) complete the UDP connection handshake reliably.
  - Updated `ConnectionScreen.kt` and `ConnectionCoordinator.kt` so switching between the Bluetooth, Wi-Fi, and Remote WAN tabs no longer severs active connections.

- **PC Server UDP Buffer, Sliding-Window Deduplication & Security Hardening (`pc_server/server.py`, `AndroidManifest.xml`, `CompanionSessionService.kt`)**:
  - Expanded the UDP socket receive buffer from `2048` bytes to `65507` bytes, preventing Windows `WSAEMSGSIZE` (`WinError 10040`) drops on phone camera frames and large payloads.
  - Replaced strict `seq <= last_seq` dropping with a bounded 512-entry sliding replay window (`_seen_cmd_seqs`), dropping exact duplicate packets across concurrent transports without discarding slightly out-of-order UDP mouse/keyboard events.
  - Bound `PhoneCameraHttpServer` strictly to `127.0.0.1` instead of `0.0.0.0`, released `pyvirtualcam` instances before re-initializing, and disabled Android cloud/ADB auto-backup (`android:allowBackup="false"`).
