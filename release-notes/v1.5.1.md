# Lanyard v1.5.1

## BT Mouse is now Lanyard

- **New name**: the phone app is **Lanyard** and the Windows companion is **Lanyard for PC**.
- **New icon**: a cord meeting at a tag, white on black. On Android 13 and later it also
  follows your themed icons.
- Your phone shows up as **Lanyard** in a PC's Bluetooth list when used as a Bluetooth mouse
  and keyboard.

Nothing else changes: pairing, settings, recordings and in-app updates carry over. The app
keeps its Android package and the Windows file names, so it updates in place.

## Compatibility and Versioning

- Android app version: 1.5.1 (version code 30).
- Windows companion and server protocol version: 1.5.1.
